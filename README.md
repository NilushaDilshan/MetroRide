# 🚗 MetroRide

MetroRide is a **vehicle booking and transportation management system** developed as a **group project** for the **Higher National Diploma in Information Technology (HNDIT)** program at **SLIATE ATI Kandy**.

The system provides a simple, responsive, and user-friendly platform that allows users to browse available vehicles and make bookings online, including wedding vehicle reservations.

---

## ✨ Features

* User Registration and Login
* Browse Available Vehicles
* Vehicle Booking
* Wedding Vehicle Booking
* Vehicle Management
* Search and Filter Vehicles
* Form Validation
* Responsive User Interface
* Interactive User Experience

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Media Queries
* JavaScript (ES6)
